# FlashSaleSystem - Enterprise Software Architecture

An enterprise-oriented desktop application built in Java demonstrating advanced Object-Oriented Programming (OOP) and structural/creational design patterns.

## Implemented Design Patterns
* **Proxy:** Access control and secure logging for critical transactions.
* **Facade:** Unified interface simplifying interactions across complex subsystem operations.
* **Adapter:** Standardizing disparate data sources into compatible interfaces.
* **Singleton:** Global management of configuration states and system instances.
* **Abstract Factory & Builder:** Flexible and decoupled instantiation of system entities and order configurations.

## Tech Stack
* Java (JDK 17+)
* Java Swing (GUI)
* Git

## Key Features
* Clean separation of concerns between business logic, presentation, and data management.
* Extensible architecture allowing modular additions of new payment methods and sale events.
